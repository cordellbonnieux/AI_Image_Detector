Pipeline summary:
1. Data loading: train.py loads labeled images from DATA_TRAIN_PATH using Torchvision (testing images at DATA_TEST_PATH)
2. Preprocessing: preprocess.py does training transforms (crop, resized, flip, rotate, color jitter, and normalize) and test transforms (resize, crop, normalize)
3. Model: ai_detector.py uses pretrained RestNet-18; two class prediction (binary), either 'AI Generated' or not.
4. Training:
    - Loss: CrossEntropyLoss
    - Optimizer: Adam
    - LR Scheduler: ReduceLROnPlateau
    - Loop over epochs, backpropagate and update weights
    - Checkpoint saving
5. Evaluation:


- raw/train/test images → preprocess → model training → checkpoint
- checkpoint → predictor → new image inference
- test dataset → accuracy + confusion matrix
