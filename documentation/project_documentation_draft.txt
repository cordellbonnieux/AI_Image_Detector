Project Documentation Draft for Group 14 - AI Image Detector

1. How-To Guide
================

Overview
--------
This guide explains how to build, train, and run the AI image detector in this repository. The system uses PyTorch and transfer learning with a pretrained ResNet18 model to classify images as either "AI Generated" or "Not AI Generated." It also includes a Flask web API that accepts image uploads and returns prediction results.

Tasks and techniques documented:
- Dataset organization using torchvision ImageFolder
- Preprocessing with PyTorch transforms
- Fine-tuning a pretrained ResNet18 model
- Training loop and scheduler usage
- Evaluation with accuracy checking and confusion matrix plotting
- Running predictions from a command line script
- Troubleshooting common setup and runtime issues

Step-by-step instructions
-------------------------
1. Activate the virtual environment
   - `source venv/bin/activate`

2. Install dependencies
   - `python -m pip install -r requirements.txt`
   - Dependencies include `torch`, `torchvision`, `Pillow`, `numpy`, `Flask`, and `tqdm`.

3. Verify dataset structure
   - The project expects training data in `data/raw/train` and test data in `data/raw/test`.
   - Each of those directories should contain class subfolders: `fake` and `real`.
   - The example dataset used is CIFAKE: https://github.com/jordan-bird/CIFAKE-Real-and-AI-Generated-Synthetic-Images

4. Understand preprocessing
   - `src/utils/preprocess.py` defines train and test transforms.
   - Training images are processed with:
     - `RandomResizedCrop(IMAGE_SIZE)`
     - `RandomHorizontalFlip()`
     - `RandomRotation(10)`
     - `ColorJitter(...)`
     - normalization with ImageNet mean/std.
   - Test images are resized and center cropped to `IMAGE_SIZE = 224`.

5. Inspect the model architecture
   - `src/models/ai_detector.py` defines `AIDetectorCNN`.
   - With `use_pretrained=True`, it loads `torchvision.models.resnet18`.
   - The final fully connected layer is replaced with `nn.Linear(..., num_classes)` for binary classification.

6. Train the model
   - Run `python -m src.training.train`
   - The script uses `ImageFolder`, `DataLoader`, and `CrossEntropyLoss`.
   - `train.py` sets `shuffle=True` for the training loader and `shuffle=False` for the test loader.
   - The optimizer is Adam with `lr=1e-4` and weight decay `1e-4`.
   - The learning rate scheduler is `ReduceLROnPlateau`, stepped on average epoch loss.

7. Evaluate the model
   - `src/utils/accuracy.py` contains `check_accuracy(loader, model, device)` which iterates through a data loader in evaluation mode and prints overall accuracy.
   - There is a small evaluation utility at `src/utils/evaluate.py` that loads a saved checkpoint, runs `check_accuracy` on the test set, and produces a confusion matrix image.
   - Usage:
     - Run the evaluator with the default checkpoint:
       - `python -m src.utils.evaluate`
     - Specify a different checkpoint or output file:
       - `python -m src.utils.evaluate --model-path path/to/checkpoint.pth --confusion-path output_confusion.png`
   - Output:
     - The script prints the overall test accuracy to stdout.
     - A confusion matrix PNG is written to `confusion_matrix.png` (or the path given with `--confusion-path`).

8. Run predictions
   - Use `python -m src.app.predict path/to/image.jpg`
   - `src/app/predict.py` loads the saved checkpoint from `checkpoints/ai_detector.pth`.
   - It applies the same test transforms before prediction and prints class and confidence.

9. Web app
   - `src/app/app.py` provides a Flask web API.
   - Run it with `python -m src.app.app`.
   - Send a POST request to `/predict` with a form field named `image`.
    (for example: curl -X POST -F "image=@/full/path/to/image.jpg" http://localhost:5000/predict)
   - The endpoint returns JSON containing the predicted class, confidence, and class probabilities.

Troubleshooting tips
--------------------
- "ModuleNotFoundError: No module named 'torch'"
  - Activate your virtual environment and install requirements.
  - `source venv/bin/activate && python -m pip install -r requirements.txt`

- "RuntimeError: shape mismatch" or image size errors
  - Ensure `IMAGE_SIZE` is consistent at `224` in `src/config.py`.
  - Ensure training and prediction use the same transforms.

- "FileNotFoundError: Model checkpoint not found"
  - Confirm training saved `checkpoints/ai_detector.pth`.
  - If not, rerun training and verify `CHECKPOINT_DIR`.

- Data loader problems
  - Verify the directory structure for `data/raw/train` and `data/raw/test`.
  - Ensure each class folder contains valid image files.

- Web app failures
  - Ensure the Flask app is run after the model checkpoint is trained and saved.
  - Validate that the POST request uses the `image` field and a valid image file.

Known limitations in this project
--------------------------------
- No validation split or separate validation set is implemented.
- No confusion matrix or cross-validation is implemented.
- Default `EPOCHS = 1` in `src/config.py` is too low for reliable training.
- The Flask app endpoint is incomplete and not currently production-ready.


2. Project Write-Up
===================

System Explanation
------------------
What does the system do?
- The system classifies input images as either AI-generated or not, using a binary image classifier built with PyTorch.

What AI methods are used?
- Transfer learning with a pretrained ResNet18 model from `torchvision`.
- Fine-tuning the final layer for binary classification.
- Data augmentation via PyTorch image transforms.

AI pipeline description
- Input: image files loaded from `data/raw/train` and `data/raw/test`, organized with class subfolders.
- Preprocessing: images are cropped/resized, augmented, normalized, and converted to tensors.
- Model: `AIDetectorCNN` wraps a pretrained ResNet18 and replaces its final classification layer.
- Output: class prediction and confidence score, currently shown by `src/app/predict.py`.

Diagrams / architecture
- This repository does not currently include explicit diagram files.
- The model architecture is ResNet18 with the final `fc` layer changed to output 2 classes.

Limitations and mitigation
- Limitation: only overall accuracy is measured, no confusion matrix or class-specific diagnostics.
  - Mitigation: add a validation split and calculate per-class accuracy/confusion matrix in future work.
- Limitation: default training epochs is only 1.
  - Mitigation: increase `EPOCHS` and monitor loss and validation performance.
- Limitation: Flask app is incomplete.
  - Mitigation: complete the endpoint with proper preprocessing and checkpoint loading.
